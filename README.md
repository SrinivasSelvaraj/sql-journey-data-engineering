# SQL Journey for Data Engineering

This repository is set up for a simple daily GitHub streak habit: make one real commit per day by adding a small SQL note, exercise, or reflection.

## Daily workflow

1. Open `daily/` and add today's note.
2. Solve one small SQL exercise in `exercises/`.
3. Commit the change with a clear message.

## Suggested streak rule

- Minimum daily change: 1 note, 1 query, or 1 lesson learned.
- Keep each commit small and reviewable.
- If you miss a day, resume immediately instead of trying to backfill.

## Starter structure

- `daily/` - short daily log entries.
- `exercises/` - SQL practice files.
- `notes/` - reusable study notes.

## First commits you can make

- `chore: add repo scaffold`
- `docs: add daily streak plan`
- `feat: add first SQL practice note`
