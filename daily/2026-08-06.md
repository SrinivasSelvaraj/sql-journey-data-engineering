## One SQL query or idea

```sql
-- Fill date gaps using a recursive CTE
WITH RECURSIVE dates AS (
    SELECT '2026-01-01'::DATE AS dt
    UNION ALL
    SELECT dt + INTERVAL '1 day' FROM dates WHERE dt < '2026-01-31'::DATE
),
actuals AS (
    SELECT DATE_TRUNC('day', job_posted_date)::DATE AS dt, COUNT(*) AS cnt
    FROM job_postings_fact GROUP BY 1
)
SELECT d.dt, COALESCE(a.cnt, 0) AS postings
FROM dates d LEFT JOIN actuals a USING (dt);
```

## What I learned

- WITH RECURSIVE needs an anchor (non-recursive base) + a recursive term joined with UNION ALL
- `->>` returns TEXT; `->` returns JSONB — use `->>` when comparing or displaying, `->` when chaining
- Functions use RETURN QUERY to emit rows; procedures use CALL (not SELECT) and can't return values
