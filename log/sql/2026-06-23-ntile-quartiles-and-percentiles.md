# NTILE, quartiles and percentiles

*SQL for analytics and engineering*

## Concept

NTILE(4) splits rows into four equal buckets. PERCENTILE_CONT(0.5) WITHIN GROUP gives a true interpolated median. PERCENTILE_DISC returns an actual row value. Both are ordered-set aggregates.
